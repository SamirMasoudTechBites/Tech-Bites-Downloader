Tech Bites Downloader ("we", "our", or "the extension") is a browser companion extension for Google Chrome, Microsoft Edge, and Chromium-based browsers. The extension transmits file download links, media video streams, and user-selected links to the local Tech Bites Downloader desktop application on your computer for fast multi-part downloading.

We are strictly committed to user privacy. The extension does NOT collect, store on remote servers, sell, or share personal user data with any third party.

1. Data the Extension Handles and Why

A. Download URLs and Web Addresses

When you initiate a download, click the video download overlay, or right-click a link and choose "Download with TechBites", the extension reads the URL of the target file or media stream. This URL is passed solely to the local Tech Bites Downloader desktop application via local native messaging (com.techbites.downloader). URLs are never sent to external servers or logged remotely.

B. Session Cookies

For downloads that require an active login session (such as authenticated files or authorized media), the extension accesses session cookies for that specific domain using the browser's cookies API. These cookies are passed strictly to your local desktop application so the download can authenticate. Cookies are never transmitted to our servers or any third-party service.

C. Local Settings and Preferences

User configurations (such as download interception toggle, domain allow-lists, and block-lists) are stored locally in your browser profile using chrome.storage.local. This data never leaves your device.

2. What We Do NOT Do (Data Protection Principles)

  • Zero Remote Collection: We do not operate remote tracking or collection servers. Zero bytes of user data are transmitted to external servers.
  • No Sale or Transfer: We never sell, rent, monetize, or transfer user data, browsing history, or cookies to third parties, brokers, or advertisers.
  • No Tracking or Advertising: Handled data is never used for advertising, behavior profiling, or creditworthiness assessment.
  • No Remote Code: The extension executes only packaged local code and loads no external scripts.
  • Single Purpose: All permissions and data access are strictly limited to facilitating file and video downloads as requested by the user.

3. Browser Permissions and Justifications

4. Desktop Application Integration

The Tech Bites Downloader desktop application is a separate Windows application. Communication between this extension and the desktop app occurs strictly on your local machine using standard local Native Messaging.
